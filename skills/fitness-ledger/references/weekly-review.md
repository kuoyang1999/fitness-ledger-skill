# 每周维护

**简体中文** · [English](weekly-review.en.md)

先读项目入口、索引与协作规范、记录模板和上次成功周检的日志条目。首次接手已有账本时，把实际读到的对象和配置登记为起点。查询返回空时检查权限、视图筛选和分页。若用户要求初始化，在指定入口建立本次需要的原库，并将返回的真实地址记入私有索引。

## 确定检查范围

- 依项目时区取上一完整周的作息标签，默认从周一到下一个周一，含起点、不含终点。记录实际查到的周期 ID、UTC 起止和未闭合周期。跨过周一午夜的清醒活动仍可能属于上一周末的周期。
- 分别查本周发生的原事件、上次检查后创建或修改的记录、较早的迟到补录、上次留下的待核项。已发生但缺少周期的事件按已知实际日期或旧标签另列，并注明用的是哪一种。
- 先读实时字段和视图配置。按可查范围检索，翻到最后一页。没有完整变更流时，使用可见视图、相关原页和已知问题作定向复核，注明覆盖、截止和缺口。设备与专项聊天分别说明实际读取范围。

## 查找会影响结果的问题

| 检查对象 | 复核重点 |
| --- | --- |
| 作息与汇总 | 用主醒来及稳定周期 ID 核对边界。检查同一原事件是否挂了多个周期、开日主睡眠是否被计入两天、阶段摘要是否误写最终日结。核对晚同步修订后的事件与摘要。 |
| 摄入 | 核对实际摄入状态、份量单位、来源与生效版本。用计入的原事件复算已记录小计，说明缺失和估算。产品标签保留每份口径，组合内重复成分核对实际份数。 |
| 训练与体测 | 父记录统计事件，子记录保存组、分段或逐项读数。核对设备镜像、单位、组数、平均值与总和。同日多次真实活动保留各自身份。 |
| 计划 | 对照已确认版本及实际训练。进度摘要引用完成来源，缺分段时保留分段待核，部分采纳只更新对应范围。 |
| 数据源与依赖 | 对照索引、模板、看板与实际字段。汇总值无法直接读取时，从允许计入的原记录复算并标明方法。旧日期汇总单独保留。 |

## 导航与修复

实际读取主入口、每个现有模块的直属对象及相关视图的来源，与上次位置和对象 ID 比较。七模块基线见 [Skill 入口](../SKILL.md)。新增快捷视图、辅助规则和逐组明细放回所属模块。真正独立的新主题可增设入口并登记理由，跨模块使用页面提及或关联视图。

对归属明确且共享范围可核验的错放对象，先保存原位置、ID、视图筛选和排序，再在原项目内移动原对象。写后打开原链接、核对新父链、配置和依赖。涉及权限、真实记录合并或改变历史统计含义时，给出对象、影响及最小方案供用户决定。

局部更正前重读原值与来源，更正后回读受影响的关系、字段和摘要。归属或数字有变化时登记复核原因，完成核对后只关闭对应事项。创建结果不明时按原事件特征查重，再决定如何继续。

## 日志与通知

沿用私有维护日志中同一周的条目，并复用既有问题。写明窗口、覆盖和访问缺口，逐项给出原页、字段、证据、影响、处理结果及下一检查点。移动与结构修复保存原位置、新位置、ID和回退依据。日志排除在业务统计之外。

按项目偏好只通知新问题、状态变化、修复、访问失败或需要决定的事项。无实质变化时省去重复报告。对重复失误给出可以粘贴到对应聊天的提示词，点明应谁在什么动作之后核对哪条原记录。
